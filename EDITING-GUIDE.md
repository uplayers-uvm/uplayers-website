# How to edit the UPlayers website

No coding needed. Everything is done at **https://app.pagescms.org** → **uplayers-website**.
When you click **Save**, the live site (https://uplayers.pages.dev) updates by itself in 1–2 minutes.

> **Can't break it.** Every save is kept in history, so any mistake can be undone (ask the webmaster).

---

## The sidebar at a glance

| Section | What it controls |
|---|---|
| **Events** | Auditions, meetings, workshops, socials. Shown on the Events page and the home page. |
| **Shows** | Every production: description, dates, tickets, cast & crew, YouTube video, photo gallery. |
| **News** | Announcements and blog posts. The "News" menu link appears once you publish one. |
| **Officers** | The board: names, roles, majors, bios, headshots. |
| **Pages** | Extra pages (Join Us, Contact, or anything new, like an FAQ). |
| **Site settings** | Announcement bar, home page headline and photo, social links, mailing list link. |

**Draft switch:** most things have a **Draft** switch. While it's on, nothing shows on the website, so you can work on something and publish it later. There's an example event and an example news post saved as drafts to show you how they look.

## Common tasks

### Add an event (auditions, meeting, social…)
1. **Events** → **Add an entry**.
2. Fill in the name, type, start date/time, location, and a short summary.
3. Optional: add a **button link** (e.g. an audition sign-up Google Form) and **button text**.
4. **Save**.

It appears under "Upcoming events" on the home page and the Events page, and it **disappears by itself once it's over** (it moves to "Past events"). Visitors get an **Add to my calendar** button automatically.

### Announce something big (gold bar at the top of every page)
**Site settings** → **Announcement bar** → turn on **Show the announcement bar**, write the message, and optionally add a link → **Save**. Turn it off the same way.

### Set up the next show
1. **Shows** → **Add an entry**. Fill in the title, season, opening date, playwright, director, dates, venue, description and poster/photo.
2. Turn on **Feature on the home page as "Now playing"**. Turn it **off** on the previous show.
3. When tickets go on sale, paste the **Ticket link** and a "Buy tickets" button appears.
4. After opening, add the **Cast** and **Crew**, a **YouTube link**, and photos in **Photo gallery**.

### Add show photos
Open the show → **Photo gallery** → **Add** → upload photos (you can pick many at once) → drag to reorder → **Save**.
Photos straight from a phone are fine. If you're uploading 50+ big camera photos, ask the webmaster to shrink them first so the site stays fast.

### Update the board each year
**Officers** → change **Board year** → edit each officer, or use **Add an entry** / the delete button. Drag to reorder.
For headshots, square photos work best. Leave a field blank to hide it.

### Post news
**News** → **Add an entry** → headline, date, summary, optional image, post text → **Save**.

### Make a new page (e.g. FAQ, Costume Shop, Alumni)
**Pages** → **Add an entry** → title + content → turn on **Show in the top menu** if you want it in the menu → **Save**.
Its address comes from the title: "Costume Shop" becomes `/costume-shop`.

### Change the home page photo or headline
**Site settings** → **Home page big photo** / **Home page headline** → **Save**. Tall (portrait) photos look best.

### Connect a mailing list sign-up
Make a Google Form, then paste its link into **Site settings** → **Mailing list signup link**.

## Text formatting tips
In any big text box you can use headings, **bold**, *italic*, bulleted and numbered lists, links, and images, using the toolbar just like Google Docs.

## Who to ask
- **Adding or removing editors:** anyone who manages the Pages CMS project → **Collaborators** → invite by email.
- **New features or design changes:** the webmaster (the site's code lives at github.com/uplayers-uvm/uplayers-website).
